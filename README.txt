ALEEYOU FX — INSTALLABLE WEB APP PACKAGE

Included:
- index.html: MT5-style demo trading interface
- manifest.json: installable web app metadata
- service-worker.js: basic offline caching
- icon.svg: app icon

Starting demo balance: $10,000.

To use:
1. Extract the ZIP.
2. Open index.html in a browser to try the demo locally.
3. For the install-to-home-screen experience, host all files on an HTTPS static website.
4. Visit that HTTPS website in a supported browser and choose "Install app" or "Add to Home screen".

Important:
- The displayed prices are simulated, not live market data.
- Orders use virtual money only; no broker is connected.
- The app cannot execute real-money trades.
- PWA installability generally requires HTTPS (localhost is an exception for development).
- Real-time data and broker integration are separate future stages and may require provider accounts, API access, and compliance checks.
